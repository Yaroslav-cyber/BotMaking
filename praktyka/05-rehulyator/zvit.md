# Робота 5 — реле і П-регулятор

**Прогноз (крок 1):** П швидше в **3 рази**

| Варіант      |  Kp | Час до кінця траси, с (3 прогони) | Як виглядає рух                                 |
| ------------ | --: | --------------------------------- | ----------------------------------------------- |
| релейний     |   — | 86.5 / 91.9 / 85.6                | плавно, але дуже повільно                       |
| пропорційний | 0.5 | 26.0                              | рівно, але на середині робот зробив зайвий круг |
| пропорційний | 1.0 | 21.8                              | стабільно                                       |
| пропорційний | 1.5 | 21.8                              | стабільно та швидко                             |
| пропорційний | 2.0 | 21.9                              | стабільно                                       |
| пропорційний | 2.5 | 22.0                              | стабільно                                       |
| пропорційний | 3.0 | 23.4                              | трохи застряг на останньому повороті            |
| Kp завеликий | 3.5 | —                                 | на прямих ділянках робот сильно розгойдується   |

**Додатково:** під час першої спроби фінальних прогонів з `Kp = 1.5` робот зійшов із траси на середині та показав **33.2 с**. Цей результат не враховано у фінальних трьох прогонах, оскільки робот не пройшов трасу нормально. Три успішні прогони: **21.9 / 21.9 / 21.8 с**.

## Чому мій Kp саме такий

1. При `Kp = 1.5` робот показав один із найкращих результатів — близько **21.8–21.9 с**.
2. При збільшенні `Kp` понад 1.5 час не покращувався: при `Kp = 2.0` було 21.9 с, при `Kp = 2.5` — 22.0 с, а при `Kp = 3.0` — вже 23.4 с.
3. При `Kp = 3.5` робот почав сильно розгойдуватися на прямих ділянках, тому `Kp = 1.5` дає хороший баланс між швидкістю та стабільністю руху.
